## Beta App Description

```
indeKismet helps you make time for the friends you care about — not just keep track of them.

Paths cross. Movements happen. indeKismet is a privacy-first social presence app that shows who’s nearby and free right now, so you can reconnect at the right place and the right time. There is no feed, no posting, and no content — only coordination.

WHAT TO TRY IN THIS BETA
• Sign in with Apple and complete short onboarding (interests + availability)
• See yourself on the map and manage free/busy windows with calendar context
• Add friends via invite codes (More → Manage friends)
• View paired friends on the map when they share encrypted location updates
• Get on-device AI suggestions for when and how to reconnect (Orbit Intelligence)
• Send a Pulse — a lightweight invitation to a friend
• Optional: Siri shortcuts such as “Who’s free nearby?”

HOW TO GET THE FULL EXPERIENCE
Best with two Apple IDs on two devices:
1. Device A: Sign in → More → Manage friends → Create invite code
2. Device B: Sign in → Redeem the invite code
3. Allow Location (When In Use) on both devices
4. Open Map — paired friends appear once location is shared

WHAT TO TEST
1. Sign in with Apple → complete interests, calendar, and free hours
2. Map tab: allow location, confirm your pin appears
3. Two devices: create/redeem invite code under More → Manage friends
4. Both open Map with location on → friend pin + Suggestions → Send a Pulse
5. More → Sign Out, relaunch, confirm session restores
6. Radar and Timeline tabs are placeholders in this beta (expected)

PRIVACY
• Sign in with Apple only
• Location and calendar stay on-device for AI reasoning
• Friend updates are end-to-end encrypted; the server relays ciphertext only

PERMISSIONS
• Location: show you on the map and surface nearby friends
• Calendar: find free windows for spontaneous meetups
• Motion: avoid suggesting meetups while driving

Feedback: bhanagevirajvaibhav@gmail.com
```
